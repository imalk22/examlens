ExamLens Bonum
==============

ExamLensBonum-Regular.ttf is a derived version of TeX Gyre Bonum Regular
(texgyrebonum-regular.otf), (c) GUST e-foundry, a free font that closely matches
Bookman. Source: https://ctan.org/pkg/tex-gyre

Changes made for ExamLens:
  - outlines converted from CFF (PostScript) to TrueType, so the certificate PDF
    writer can embed it;
  - renamed to "ExamLens Bonum" (file ExamLensBonum-Regular.ttf), as the GUST
    Font License requests for derived fonts.

The glyph designs, metrics and kerning are unchanged.

ExamLens uses this font only when Bookman Old Style (the font in the certificate
templates) is not installed, for example on Streamlit Community Cloud. On a Windows
PC with Microsoft Office, Bookman Old Style is used.
